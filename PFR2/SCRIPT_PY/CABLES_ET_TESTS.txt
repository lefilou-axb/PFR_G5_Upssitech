🔗 CÂBLAGE USB (Raspberry → Arduino)
═══════════════════════════════════════════════════════════════════════════════

Brancher un câble USB Type A vers Type B:

  Raspberry Pi 3A+                USB Cable                Arduino Mega
  ┌──────────┐                    ─────────────────────   ┌──────────┐
  │  Port    │                                             │  Port    │
  │  USB     ├───────────────────────────────────────────►│  USB     │
  │          │     (A)              (B)                   │          │
  └──────────┘                                             └──────────┘

Résultat: L'Arduino apparaît sur /dev/ttyUSB0 (ou ttyUSB1, etc.)

TEST 1: Vérifier la connexion USB
─────────────────────────────────────────────────────────────────────────────

Sur Raspberry Pi:

  $ lsusb
  
  Doit afficher quelque chose comme:
  
  Bus 001 Device 003: ID 2341:0054 Arduino SA Mega 2560

  $ ls /dev/ttyUSB*
  
  Doit afficher:
  
  /dev/ttyUSB0

✅ SUCCÈS: Le port est /dev/ttyUSB0

❌ ÉCHEC: Pas de port → Vérifier le câble USB

TEST 2: Communication basique
─────────────────────────────────────────────────────────────────────────────

Arduino (charger le code robot_arduino_improved.cpp):

  // Code est déjà prêt, juste uploader

Raspberry Pi (créer test_com.py):

  #!/usr/bin/env python3
  import serial
  import time
  
  ser = serial.Serial('/dev/ttyUSB0', 115200, timeout=2)
  time.sleep(2)
  
  # Test 1: Envoyer une commande simple
  print("Test 1: Envoi simple")
  ser.write(b'forward 1.00\n')
  
  # Lire la réponse
  for i in range(10):
    if ser.in_waiting > 0:
      response = ser.readline().decode('utf-8').strip()
      print(f"  Arduino: {response}")
    time.sleep(0.1)
  
  time.sleep(2)
  
  # Test 2: Envoi plusieurs commandes
  print("\nTest 2: Plusieurs commandes")
  commands = [
    'forward 0.50',
    'right 45.00',
    'stop'
  ]
  
  for cmd in commands:
    print(f"Envoi: {cmd}")
    ser.write((cmd + '\n').encode())
    time.sleep(1.5)
  
  ser.close()
  print("Déconnecté")

Exécuter:

  $ python3 test_com.py

✅ SUCCÈS: Le robot reçoit les commandes et répond

❌ ÉCHEC: Pas de réponse → Vérifier le port, le baud rate (115200)

TEST 3: Calibrage distance
─────────────────────────────────────────────────────────────────────────────

Procédure:

1. Marquer 2 points à 1 mètre d'écart

2. Créer test_distance.py:

  #!/usr/bin/env python3
  import serial
  import time
  
  ser = serial.Serial('/dev/ttyUSB0', 115200, timeout=2)
  time.sleep(2)
  
  # Envoyer avance 1 mètre
  print("Envoi: forward 1.00")
  ser.write(b'forward 1.00\n')
  
  # Attendre ~5 secondes (à adapter selon le calibrage)
  time.sleep(6)
  
  # Arrêter
  ser.write(b'stop\n')
  time.sleep(1)
  
  ser.close()

3. Exécuter:

  $ python3 test_distance.py

4. Mesurer la distance réelle parcourue
   Si pas 1 mètre, ajuster DISTANCE_RATIO dans le code Arduino

🐛 DÉPANNAGE
═══════════════════════════════════════════════════════════════════════════════

Problème: /dev/ttyUSB0: Permission denied
────────────────────────────────────────
Solution:

  $ sudo usermod -a -G dialout $USER
  
  Puis redémarrer la Raspberry

Problème: Pas de fichier /dev/ttyUSB0
────────────────────────────────────────
Solution:

  $ lsusb
  
  Si Arduino n'apparaît pas: Vérifier câble USB et redémarrer Arduino

Problème: Arduino reçoit pas les commandes
────────────────────────────────────────
Solution:

  1. Vérifier baud rate: 115200 partout
  2. Vérifier Serial vs Serial1
     - Serial = USB (depuis RPi)
     - Serial1 = Bluetooth

Problème: Robot avance pas de la bonne distance
────────────────────────────────────────
Solution:

  1. Vérifier DISTANCE_RATIO calibré
  2. Vérifier la batterie
  3. Vérifier pas de perte de friction moteurs
