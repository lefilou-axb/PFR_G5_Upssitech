📍 ÉTAPE 1 : CALIBRAGE DE LA DISTANCE (AVANCE/RECULE)
═══════════════════════════════════════════════════════════════════════════════

OBJECTIF: Déterminer le ratio temps/distance pour avancer 1 mètre

MATÉRIEL NÉCESSAIRE:
  ✓ Un chronomètre ou smartphone avec app chrono
  ✓ Une règle ou mètre
  ✓ Un espace dégagé de minimum 2 mètres
  ✓ Un marqueur (crayon, scotch, etc.)

PROCÉDURE:

1. Marquer deux positions:
   - Position A : point de départ du robot
   - Position B : 1 mètre après le point A
   
   [ROBOT] -------- 1 mètre -------- [MARQUEUR]
      A                                B

2. Placer le robot à la position A

3. Dans le code, créer une fonction de TEST:
   
   ⬇️ VER LE CODE ARDUINO (LIGNE ~350) ⬇️
   
   Décommenter et modifier ce code dans setup():
   
   void setup() {
     // ... code existant ...
     
     // TEST DISTANCE (décommenter pour tester)
     // avancer();
     // delay(5000);  // ← À MODIFIER (voir étape 5)
     // stopMoteurs();
     // while(1);  // Boucle infinie pour garder le robot arrêté
   }

4. Uploader le code sur l'Arduino

5. TESTER ET MESURER:
   - Lancer l'Arduino
   - Le robot avance avec delay(5000) = 5 secondes
   - MESURER LA DISTANCE RÉELLE parcourue
   - Noter le temps et la distance
   
6. CALCULER LE RATIO:
   
   DISTANCE_RATIO = Distance réelle (en mètres) / Temps (en ms)
   
   ❗ ATTENTION: Le temps dans le code est en MILLISECONDES (ms)
      delay(5000) = 5000 millisecondes = 5 secondes
   
   EXEMPLES:
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Si le robot parcourt 1 mètre en 5000 ms:
     DISTANCE_RATIO = 1.0 / 5000 = 0.0002 m/ms
   
   Si le robot parcourt 0.5 mètres en 2000 ms:
     DISTANCE_RATIO = 0.5 / 2000 = 0.00025 m/ms
   
   Si le robot parcourt 1.5 mètres en 5000 ms:
     DISTANCE_RATIO = 1.5 / 5000 = 0.0003 m/ms
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

7. MODIFIER LE CODE:
   
   Remplacer cette ligne (LIGNE 29):
   
   #define DISTANCE_RATIO 0.4  // À CALIBRER
   
   Par votre valeur calculée (exemple):
   
   #define DISTANCE_RATIO 0.0002  // Mesuré empiriquement
   
8. VALIDER:
   - Modifier le delay(5000) pour tester d'autres distances
   - Vérifier que le robot parcourt bien la distance attendue
   
   Exemple: Pour tester 2 mètres
     delay(10000);  // 10 secondes
     
   Vérifier que le robot avance de 2 mètres ✓

🔄 ÉTAPE 2 : CALIBRAGE DE L'ANGLE (ROTATION)
═══════════════════════════════════════════════════════════════════════════════

OBJECTIF: Déterminer le ratio temps/angle pour tourner 90°

MATÉRIEL NÉCESSAIRE:
  ✓ Un chronomètre ou smartphone
  ✓ Un rapporteur ou un carré (pour 90°)
  ✓ De l'espace autour du robot

PROCÉDURE:

1. Marquer une ligne de référence:
   
   Par exemple: Placer le robot pointant vers une direction (ex: nord)
   Marquer la position du robot avec du scotch

2. Dans le code, créer une fonction de TEST:
   
   ⬇️ VER LE CODE ARDUINO (LIGNE ~350) ⬇️
   
   Modifier dans setup():
   
   void setup() {
     // ... code existant ...
     
     // TEST ANGLE (décommenter pour tester)
     // droite();  // ou gauche();
     // delay(750);  // ← À MODIFIER (voir étape 4)
     // stopMoteurs();
     // while(1);  // Arrêt
   }

3. TESTER ET MESURER:
   - Lancer l'Arduino
   - Le robot tourne avec delay(750) = 750 ms = 0.75 secondes
   - MESURER L'ANGLE RÉEL parcouru
   - Noter le temps et l'angle
   
   💡 Conseil: Utiliser un rapporteur ou une équerre pour mesurer 90°

4. CALCULER LE RATIO:
   
   ANGLE_RATIO = Angle réel (en degrés) / Temps (en ms)
   
   EXEMPLES:
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Si le robot tourne 90° en 750 ms:
     ANGLE_RATIO = 90 / 750 = 0.12 deg/ms
   
   Si le robot tourne 90° en 1000 ms:
     ANGLE_RATIO = 90 / 1000 = 0.09 deg/ms
   
   Si le robot tourne 45° en 500 ms:
     ANGLE_RATIO = 45 / 500 = 0.09 deg/ms
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5. MODIFIER LE CODE:
   
   Remplacer cette ligne (LIGNE 30):
   
   #define ANGLE_RATIO 0.12  // À CALIBRER
   
   Par votre valeur calculée (exemple):
   
   #define ANGLE_RATIO 0.09  // Mesuré empiriquement

6. VALIDER:
   - Tester avec différentes valeurs (45°, 90°, 180°)
   - Vérifier que le robot tourne bien de l'angle demandé
   
   Exemple: Pour tester 180°
     Attendre 180 / 0.09 = 2000 ms = 2 secondes
     delay(2000);
     
   Vérifier que le robot tourne de 180° ✓

📝 RÉSUMÉ DES VALEURS À TROUVER
═══════════════════════════════════════════════════════════════════════════════

À trouver lors des tests:

  DISTANCE_RATIO = __________________ m/ms

  ANGLE_RATIO = __________________ deg/ms
  
  Calcul: Angle (°) / Temps (ms)
  
  Exemple: 90° en 750 ms = 90 / 750 = 0.12 deg/ms


  OBSTACLE_DISTANCE = __________________ cm
  
  Distance minimale avant arrêt d'urgence
  (mettre environ 30-40 cm pour laisser de la marge)

⚠️  NOTES IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════

1. Les valeurs de calibrage dépendent de:
   - La batterie (niveau de charge)
   - Le poids du robot
   - La surface (lisse vs rugueuse)
   - La vitesse des moteurs

2. Recalibrer si:
   ✓ Vous changez les batteries
   ✓ Vous chargez le robot (ajouter du poids)
   ✓ Vous changez la surface de test
   ✓ Vous augmentez/diminuez la vitesse des moteurs

3. Les valeurs ne seront JAMAIS 100% précises:
   ✓ Accepter une marge d'erreur de ±5%
   ✓ Faire plusieurs tests et prendre la moyenne
   ✓ Ajuster progressivement si c'est systématiquement trop ou trop peu
