2️⃣ NOUVELLES FONCTIONS (Lignes 90-140)
   ─────────────────────────────────────────────────────────────────
   
   avancerDistance(float distanceMetres)
     ├─ Convertit distance → temps avec DISTANCE_RATIO
     ├─ Démarre le timer
     └─ Lance l'avance
   
   reculerDistance(float distanceMetres)
     ├─ Idem mais en arrière
   
   tournerAngle(float angleDegres)
     ├─ Convertit angle → temps avec ANGLE_RATIO
     ├─ Positif = droite, Négatif = gauche
     └─ Lance la rotation

3️⃣ GESTION DES OBSTACLES (Lignes 150-175)
   ─────────────────────────────────────────────────────────────────
   
   verifierObstacles()
     ├─ Lit les 3 capteurs
     ├─ Vérifie selon le type de mouvement en cours
     └─ Retourne true/false
   
   ⚠️  Si obstacle détecté:
       • Robot s'arrête
       • Recule un peu
       • Tourne du côté avec plus d'espace
       • Continue

💡 PRIORITÉS ET PRÉVENTION D'OBSTACLES
═══════════════════════════════════════════════════════════════════════════════

Hiérarchie des contrôles:

1. BLUETOOTH (Priorité MAXIMALE)
   └─ Toujours exécuté immédiatement
   └─ Arrête les mouvements en cours
   └─ Idéal pour stop d'urgence

2. DÉTECTION D'OBSTACLES (Pendant les mouvements)
   └─ Vérifiée tous les 100ms
   └─ Arrête le mouvement si obstacle < 30cm
   └─ Tente contournement automatique

3. FICHIER TEXTE (Exécution séquentielle)
   └─ Traité une commande à la fois
   └─ Attend la fin du mouvement avant la suivante
   └─ Peut être interrompu par Bluetooth

Exemple d'exécution:
┌─────────────────────────────────────────────────────────────────┐
│ Arduino reçoit: "forward 5.00"                                  │
│ ├─ Lance avancer()                                              │
│ ├─ Toutes les 100ms: vérifie obstacles                          │
│ │  └─ Obstacle détecté? → Stop + contournement                  │
│ ├─ Attends 5 secondes (selon calibrage)                         │
│ ├─ Stop                                                          │
│ └─ Prêt pour la commande suivante                               │
│                                                                  │
│ Pendant ce temps:                                                │
│ └─ Bluetooth peut intervenir à tout moment → STOP IMMÉDIAT      │
└─────────────────────────────────────────────────────────────────┘

🚀 UTILISATION PRATIQUE
═══════════════════════════════════════════════════════════════════════════════

ÉTAPE 1: CALIBRAGE (Une seule fois, ou après changements)
───────────────────────────────────────────────────────────
1. Lire le guide CALIBRAGE_ROBOT.txt
2. Faire les tests pour trouver DISTANCE_RATIO et ANGLE_RATIO
3. Modifier les valeurs dans le code Arduino (lignes 28-31)
4. Uploader le code

ÉTAPE 2: PRÉPARATION DES COMMANDES
───────────────────────────────────
1. Sur la Raspberry Pi, créer/modifier commands.txt
2. Chaque ligne = une commande
3. Format: "[commande] [valeur]"

Exemple commands.txt:
┌─────────────────────────────────────────────────────────────────┐
│ forward 1.00                                                     │
│ right 90.00                                                      │
│ forward 0.50                                                     │
│ left 45.00                                                       │
│ stop                                                             │
└─────────────────────────────────────────────────────────────────┘

ÉTAPE 3: EXÉCUTION
──────────────────
1. Brancher l'Arduino en USB à la Raspberry Pi
2. Sur la Raspberry Pi, exécuter:
   
   python3 send_commands_rpi.py

3. Le script:
   ├─ Trouve le port Arduino
   ├─ Envoie chaque commande
   ├─ Attend que le robot execute
   ├─ Reçoit les messages du robot
   └─ Affiche tout dans le terminal

ÉTAPE 4: MONITORING
───────────────────
Ouvrir le moniteur série Arduino à 115200 baud pour voir:
  ✓ Les commandes reçues
  ✓ Les distances mesurées
  ✓ Les obstacles détectés
  ✓ Les erreurs

⚙️ VARIABLES IMPORTANTES À COMPRENDRE
═══════════════════════════════════════════════════════════════════════════════

isMoving (bool)
  └─ Indique si le robot est en mouvement
  └─ Utilisé pour checker les obstacles

moveStartTime (unsigned long)
  └─ Timestamp du début du mouvement (en ms)
  └─ Utilisé pour calculer le temps écoulé

moveDuration (unsigned long)
  └─ Durée totale du mouvement (en ms)
  └─ Calculé: distance/speed ou angle/rotation_speed

currentMoveType (int)
  └─ 1 = Avance
  └─ 2 = Recule
  └─ 3 = Tourne gauche
  └─ 4 = Tourne droite
  └─ Utilisé pour vérifier les obstacles du bon côté

motorSpeed (int)
  └─ Vitesse PWM des moteurs (0-255)
  └─ Actuellement: 200
  └─ À augmenter pour plus rapide, diminuer pour plus lent

❓ QUESTIONS FRÉQUENTES
═══════════════════════════════════════════════════════════════════════════════

Q: Le robot n'avance pas de la bonne distance
R: Il faut calibrer DISTANCE_RATIO (voir CALIBRAGE_ROBOT.txt)

Q: Le robot tourne pas du bon angle
R: Il faut calibrer ANGLE_RATIO (voir CALIBRAGE_ROBOT.txt)

Q: Le robot s'arrête en plein mouvement
R: Obstacle détecté. Augmenter OBSTACLE_DISTANCE ou l'écarter

Q: Le Bluetooth ne marche plus
R: Vérifier que Serial1 commence à 115200 (ligne 218)

Q: Le robot reçoit pas les commandes du fichier
R: Vérifier le port USB (ls /dev/ttyUSB* sur Raspberry)

Q: Comment je sais que le robot a fini un mouvement?
R: Attendre isMoving == false ou lire "✅ Mouvement terminé" en serial
